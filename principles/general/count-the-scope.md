# Count the scope

**Apply:** when told "all of these", "all related" or "until everything's fixed".
When told "all the related issues / all of these / until everything's fixed":
1. Enumerate the set first (issue numbers or a list) and show it. If membership is unclear, state your reading in one line and proceed.
2. Report progress as X of N with each item's state (done / PR / blocked) and the PR link or reason.
3. Never end on a vague "done". An item not finished is named, not omitted.
