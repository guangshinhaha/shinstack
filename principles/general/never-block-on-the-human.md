# Never Block on the Human

**Apply:** when tempted to ask "should I do X?".

Reversible work proceeds. Show the result and the reasoning instead of asking.
- Reversible local work (write code, edit notes, split tasks, run tests): just do it.
- Product direction and preference calls: ask. Observable facts: run something instead of asking.
- Which actions need the user's approval (push, PR, merge, deploy, shared or production environments) is set by the repo's mode: read `approval-modes`.
- In every project: never type credentials (the user signs in), and never touch sensitive personal data.
