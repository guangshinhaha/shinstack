# Own view first

**Apply:** when making a design or "which approach" call.
Starting from the model's plan anchors the human to its framing.
- On a design or "which approach" call, state the question and the 2-3 real options with a recommendation and the main risk, with the usual practice if asked. Recommend one.
- Don't present your plan as settled. Say what would change your mind.
- If a fact can be observed by running something, run it instead of debating it.
