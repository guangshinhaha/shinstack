# Session state

**Apply:** when resuming, pausing or finishing work.
Work must be resumable by someone with no memory of this session (including the user tomorrow).
- Starting a session on existing work: first find the last state (git log, open PR/issues, any notes file) and say "goal / done / next" in 3 lines before doing anything. Don't make the user ask "where did we stop?".
- Pausing or finishing: leave the same three lines (goal, done, next + blockers) in the final reply, or in the PR/issue if the work is long-running.
